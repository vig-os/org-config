# [PR 308](https://github.com/vig-os/org-config/pull/308) chore(config): add tessera Signed commits ruleset

## Description

Part 1 of #305: lifts tessera's `Signed commits` ADR-0008 exception. Part 2
(the `Tag protection` bypass) stays open, tracked on #305.

- `orgs.signedCommits()` is added to the tessera block in
  `otterdog/vig-os/vig-os.jsonnet`, in the same position other tier-A repos
  carry it (before `Tag protection`), and the exception comment explaining
  why it was missing is deleted. The Tag-bypass exception comment and
  everything else in the block is untouched.
- The `tessera` "No `Signed commits`" row is dropped from the ADR-0008
  exceptions table. The Tag-bypass row and the `dev` default-branch row stay.
- `CHANGELOG.md` `## Unreleased` / `### Security` gets one bullet in the same
  style as #298's and #304's entries.
- `tests/test_app_actors.py`: `just test` / `uv run pytest tests/ -q` — all
  224 tests pass unchanged. `signedCommits()` has no bypass actor, so the
  App-actor ground-truth ("20 bypass sites") is unaffected; no test edit was
  needed.

## The precondition is NOT met

unsigned commit — is not satisfied today. `signedCommits()` is a `~ALL`
ruleset with **no bypass actor**: from the moment this is applied, any
further unsigned push to any tessera branch (`dev`, `main`, or a PR branch)
is rejected outright.
