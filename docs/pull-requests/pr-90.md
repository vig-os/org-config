# [PR 90](https://github.com/vig-os/org-config/pull/90) fix(config): declare devkit-upgrade org secrets

Declares the `DEVKIT_UPGRADE_APP_ID` + `DEVKIT_UPGRADE_APP_PRIVATE_KEY` org secrets that have existed live since the 1.5.x provisioning (vig-os/devkit#1302) but were never added to the config — the drift sweep correctly flagged them as undeclared. Declaring them (with `value: '********'`, values managed out-of-band) is the resolution; the "remove" direction would break the devkit-upgrade workflow in every consumer.

The same declaration landed for the exo-pet org in exo-pet/org-config#5, provisioned today.

Closes #82
