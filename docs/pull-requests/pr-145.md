# [PR 145](https://github.com/vig-os/org-config/pull/145) chore(config): adopt otterdog 1.4.0 and restore numeric status-check prefixes

## Summary

Resolves both horns of the dilemma documented in #69, and with it the twelve phantom drift issues #130–#141.

- **Otterdog pin 1.3.4 → 1.4.0** — `justfile.project` (SSoT, ADR-0005) plus the three hand-maintained `template/.github/workflows/{plan,apply,drift}.yml` literals (#56). 1.4.0 ships the upstream fix for eclipse-csi/otterdog#695 (PR eclipse-csi/otterdog#700): a numeric `<integration_id>:<context>` status-check token is now **written** as `integration_id` instead of being resolved as an app slug (`GET /apps/15368` → 404, the failure behind every broken ruleset write since #65).
- **Eighteen status-check tokens reverted** from `github-actions:X` back to `15368:X` in `otterdog/vig-os/vig-os.jsonnet`, undoing `3487ed9` (#129). The read path is unfixed *and structurally unfixable for first-party apps*: otterdog's id→slug injection consults only `GET /orgs/{org}/installations`, and `github-actions` (app_id 15368) is never an org installation, so live rulesets always render numeric. The #129 slug migration therefore produced a permanent phantom `15368:X → github-actions:X` diff on all twelve app-bound rulesets — filed by the drift layer as #130–#141.
- **Canonical prefix form is per-app** (numeric for first-party apps, slug for org-installed ones), recorded as an inline comment at the first status-check list.
- CHANGELOG `Unreleased → Fixed` entry.

## Verification

- `just precommit` (actionlint, zizmor, jsonnetfmt, `otterdog@1.4.0 validate --local`, full hook suite): green locally.
- `just test`: 43/43 — L1 plan-fixture recheck per ADR-0007 (1.4.0's only ruleset change is the write path; fixture format unchanged).
- **Merge gate**: this PR's own plan check runs otterdog **1.4.0** against live — it must report an **empty diff** (modulo the known-benign `vs-dolt` note), proving the phantom is gone before merge.

## After merge

- Apply on `main` is a no-op (config == live); next scheduled Drift run auto-closes #130–#141; #69 closes with a resolution note.
- The `gh api` manual-PUT interim from #69 remains the documented fallback until a real ruleset write under 1.4.0 confirms the write fix end-to-end (nightly Testbed E2E exercises it).
