# [PR 192](https://github.com/vig-os/org-config/pull/192) docs(readme): retire stale rulesets-not-writable known limitation

## Description

Retires the README's stale "rulesets are not machine-writable" known-limitation. The claim has been false since the otterdog 1.4.0 pin closed #69 (PR #145), was confirmed end-to-end by PR #148, and re-confirmed on 2026-08-21 when #186's ordinary apply wrote to live ruleset 13401788 with no manual `gh api` step.

Rather than deleting the now-empty section, the bullet is replaced with what is actually still open at the pinned version: the private-repo ruleset **read** gate (#107, upstream eclipse-csi/otterdog#729), which forces a private Team-plan downstream org (exo-pet) to manage repo rulesets by hand with the declaration held out of the jsonnet.
