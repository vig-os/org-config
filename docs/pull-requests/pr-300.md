# [PR 300](https://github.com/vig-os/org-config/pull/300) chore(config): declare ADR-0008 tier rulesets on h5v, nvd-mirror, vigos-mvp, vs-dolt

## Description

PR 3 of the #294 plan. It declares [ADR-0008](docs/adr/0008-repository-protection-and-merge-policy.md) tier rulesets on the four public repos that had none: `h5v` (tier A), `nvd-mirror`, `vigos-mvp` and `vs-dolt` (tier B). Each ruleset was decided after checking every automated writer on the live repo (default-branch workflows via the Contents API, registered workflows and their recent runs, branches, tags, commit signatures, org secret grants).

Nothing else changes: the rendered config differs from `main` only in the `rulesets` of these four repos; org-level settings and every other repo are byte-identical.

### How each automated writer was checked

- **h5v** (devkit 1.17.0, `DEVKIT_WORKFLOW=trunk`, no `dev` branch, no tags or releases yet). `CI Summary` confirmed on PR #7's head (`77d190a`) as a github-actions (15368) check run. Writers: `sync-issues.yml` commits to `main` as the Commit App because `DEVKIT_SYNC_TARGET` is empty. **Decided: no bot bypass on Main** — that nightly sync is refused until vig-os/h5v#9 retargets it to `sync/issue-mirror`; `prepare-release`/`release-core`/`release` rollback write `release/X.Y.Z` as the Commit App only (`abandon-release` deletes it as the Release App, which `allows_deletions` permits); tags are created by `release-publish` and RC tags pruned by `promote-release` as the Release App; `devkit-upgrade` builds its commit through `git/commits` (signed); Renovate platform commits are signed (checked on org-config's Renovate PRs). The release PR into `main` is merged with `gh pr merge --merge` after the human approval, same as `org-config`.
- **nvd-mirror**: `refresh.yml` checks out `gh-pages` and force-pushes an unsigned orphan commit there with `GITHUB_TOKEN` every 6 h; it never touches `main`. github-actions cannot be a bypass actor, so `gh-pages` is excluded from signing. All 4 `main` commits are signed; no PR workflow → no required check.
- **vigos-mvp**: no workflows at all; every commit on all 4 branches is signed by its human author.
- **vs-dolt**: fork of `dolthub/dolt-workbench`, 0 commits ahead / 405 behind. None of its upstream workflow files are registered on the fork (only CodeQL default setup runs, which writes nothing). Upstream lands unsigned commits, so no signing rule. Consequence: updating from upstream now needs a PR; the one-click "Sync fork" is a direct push that Main refuses.

### ADR-0008 exceptions added

- `nvd-mirror` Signed commits: `refs/heads/gh-pages` excluded.

## Changelog Entry

### Changed

- **`h5v`, `nvd-mirror`, `vigos-mvp` and `vs-dolt` are protected, each on its [ADR-0008](docs/adr/0008-repository-protection-and-merge-policy.md) tier** ([#294](https://github.com/vig-os/org-config/issues/294)): the four public repos that carried no ruleset at all — `h5v` merged a 128-file workflow rewrite with no review and no check — now declare them through the house shapes, each decided after checking every automated writer on the live repo. Live changes, exactly: **`h5v`** (tier A, devkit 1.17.0 trunk scaffold) gains `Main protection` requiring `15368:CI Summary` (the aggregator its PRs into `main` report) with only the house org-owner bypass, `Release protection` on `release/*` with `CI Summary` and a `commit-action-bot` bypass (the Commit App is the only writer of release branches), `Signed commits` on `~ALL` (every bot commit there is an API commit that GitHub signs), and `Tag protection` with `vig-os-release-app` as the only tag writer; **`nvd-mirror`** (tier B) gains `Main protection` without a required check and `Signed commits` with `refs/heads/gh-pages` excluded; **`vigos-mvp`** (tier B) gains `Main protection` without a required check and `Signed commits`; **`vs-dolt`** (tier B) gains `Main protection` without a required check and no signing rule, because the upstream it is forked from lands unsigned commits — and updating it from upstream now takes a PR, since the one-click "Sync fork" is a direct push. Tier B now also carries `Signed commits` wherever every writer already signs, which ADR-0008's tier table states. One new ADR-0008 exception, commented next to its override: `nvd-mirror`'s signing rule skips `gh-pages`, which `refresh.yml` force-pushes as an unsigned orphan commit with the Actions token, an actor no ruleset can list as a bypass. `h5v`'s Main carries no bot bypass, so its nightly issue sync, which still commits straight to `main` (vig-os/devkit#1227), is refused until [vig-os/h5v#9](https://github.com/vig-os/h5v/issues/9) retargets it to `sync/issue-mirror`.
