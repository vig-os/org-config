# [PR 238](https://github.com/vig-os/org-config/pull/238) docs(adr): correct ADR-0007's L2 every-PR claim

Closes #235.

## What

ADR-0007's L2 bullet claimed the live read-only `otterdog plan` runs "on every
same-repo PR". It never has: `plan.yml` carried a `pull_request` `paths:` filter
in its very first commit (`f101cc6`, 2026-07-17 — the day the ADR was accepted).

- The L2 bullet now states the real trigger set (config, plan workflow, otterdog
  pin) and points at the correction.
- The falsified claim is recorded as a dated entry in the previously empty
  `## Corrections` block, matching #225's handling of ADR-0005 — including why
  the filter is narrow (a plan is a live-API round trip on a full App
  installation token; a README typo buys no new signal) and what a wrong
  boundary costs (#230: #229's pin bump got no plan, and its acceptance evidence
  had to come from `workflow_dispatch` run 35844030809).
- A supersession trigger is added for #236, whose skip-job-shim option would
  drop the filter and retire this correction.
- Changelog entry under `## Unreleased` → `### Changed`.

## Notes for review

- `docs/issues/issue-1.md:334` repeats the stale "every same-repo PR" wording —
  deliberately untouched: it is an archived verbatim transcript of issue #1's
  plan comment, and amending an archived record would be worse than the stale
  claim. ADR-0007 is the authoritative statement.
- `README.md` already said "`plan` on every **config** PR" and needs no change;
  the correction says so explicitly.
- Documentation only; no engine, config, or workflow behaviour change. No plan
  run expected (no config path touched) — which is, fittingly, the corrected
  behaviour describing itself.
