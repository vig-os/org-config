# [PR 174](https://github.com/vig-os/org-config/pull/174) fix(drift): grant contents read so private downstream callers check out

One-line fix for #173, found by exo-pet's first real downstream drift run on v1.2.0: `permissions: {}` on the drift job → zero-scope `GITHUB_TOKEN` → `fatal: repository not found` checking out the (private) caller. The engine repo is public, so its own runs — including the #169 validation — never exposed it. Now `contents: read`, matching reusable plan/apply; the read-only security model is unchanged (all org reads / issue writes ride the App tokens).
