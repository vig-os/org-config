# [PR 193](https://github.com/vig-os/org-config/pull/193) chore(config): tune sync-issues-action rulesets — drop inert code-owner review, require up-to-date branches

## Description

Ruleset tuning on `sync-issues-action` (and one flag on `devkit-smoke-test`), implementing the two change-requests split out of the #184 evaluation — one commit per issue:

1. **#187** — the `requires_code_owner_review` flag becomes an explicit `false` on `sync-issues-action` Dev + Main protection and `devkit-smoke-test` Dev protection. Both repos carry the devkit-seeded CODEOWNERS stub with every rule commented out, so the flag never demanded anything; populating the stub would recreate the #115 unsatisfiable single-owner gate. `org-config`'s own flag stays — its CODEOWNERS binds (7 active rules).
2. **#188** — `strict: true` joins `sync-issues-action` Main protection's `required_status_checks` (checks must run against the merge result, not a stale base; precedent: `commit-action` and devkit), and the repo's `allow_update_branch` flips to `true` so the Update-branch button satisfies the requirement without a manual rebase.
