# [PR 241](https://github.com/vig-os/org-config/pull/241) docs(adr): retire ADR-0007's pre-#63 dev-trunk references

Closes #237.

## What

ADR-0007 still described the pre-#63 branch topology in four places: the
binding credential rule (apply "runs only from trunk (`dev`)"), the split
cadence ("applies from `dev` on merge"; engine "releases to `main` + version
tags"), Axis B's chosen option ("Config from `dev`; engine to tags"), and the
"not a silent `dev` merge" Consequences bullet. #63 retired `dev`: `main` is
the single trunk and applied-state branch, and the engine releases as version
tags cut by the devkit release train.

All four are corrected in place, and the reconciliation is recorded as a dated
entry in ADR-0007's `## Corrections` block alongside #235's — the decisions
themselves (trunk-only environment-gated apply; config-on-merge vs
engine-by-tag cadence) survive unchanged, only the branch names were stale.

## Notes for review

- The credential rule is the reference that mattered: a reader auditing where
  the write token can run was pointed at a branch that no longer exists.
- Found while #236 amended the same document; kept out of #235/#236 per the
  single-issue scope rule.
- Documentation only; no workflow, config, or behaviour change. May need a
  trivial changelog rebase if #240 merges first — both insert at the top of
  `### Changed`.
