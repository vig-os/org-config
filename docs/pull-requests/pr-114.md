# [PR 114](https://github.com/vig-os/org-config/pull/114) chore(config): declare devkit-upgrade client-id org secret

## Summary

Declares the `DEVKIT_UPGRADE_APP_CLIENT_ID` **organization** secret in `otterdog/vig-os/vig-os.jsonnet`, alphabetically beside the existing `DEVKIT_UPGRADE_APP_ID`.

The secret was created live on the `vig-os` org on 2026-08-07; this PR is the config-side half of the pair, so the declaration matches the org rather than drifting from it.

## Style

Matches the existing `COMMIT_APP_CLIENT_ID` / `RELEASE_APP_CLIENT_ID` entries: dummy `'********'` value, **no** `visibility` field — `vig-os` org secrets are visibility `all` by convention.

## Context

Pre-work for **phase 4** of the App-secret consolidation program tracked in #112. The devkit release that renames `DEVKIT_UPGRADE_APP_ID` -> `DEVKIT_UPGRADE_APP_CLIENT_ID` in the `devkit-upgrade.yml` scaffold is vig-os/devkit#1365. Both secrets coexist until every consumer is re-scaffolded; the numeric `DEVKIT_UPGRADE_APP_ID` is retired in a later phase.

## Expected plan

`0 to add, 1 to change, 0 to delete` — dummy-valued secrets are skipped by otterdog, so the new declaration itself produces no diff; the single change is the standing `vs-dolt` artifact.

## Checks

- `just precommit` green (all hooks passed).
