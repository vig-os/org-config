# [PR 151](https://github.com/vig-os/org-config/pull/151) feat(drift): assert unmanaged live controls the otterdog schema cannot model

Extends the drift layer with an unmanaged-controls assertion leg: a declarative table (`unmanaged-controls.toml`) of live GitHub controls the otterdog schema has no field for, checked with direct API reads and reconciled as a third issue population (`drift` + `critical` + `unmanaged-control`) under the ADR-0002 fingerprint lifecycle.

## What's in here

- **`src/drift_layer/controls.py`** — TOML loader, dotted-path selector (no jq, zero-deps doctrine), and `evaluate_controls` with per-row degradation: a 404/403/network failure withholds that row's issue from reconciliation instead of phantom-closing it. A `tolerated` field records known divergences (org SHA pinning pending #120; devkit secret-scanning extras stuck by the GHAS entitlement) while keeping the *desired* value asserted — any third value still opens an issue.
- **`github_client.py`** — typed `ApiError`, generic `get_json`, paginated org-secret reads.
- **`inventory.extract_declared_org_secrets`** — org-secret visibility and `selected_repositories` assertions derived from the committed jsonnet at run time (never hand-duplicated), aggregated one issue per family, plus an undeclared-live-secret check.
- **`cli.py`** — `--unmanaged-controls` (missing file → leg skipped) and `--controls-report` (read-only per-row outcome table); three-way population partition.
- **Seed table** — 12 assertion rows + generated org-secret families, every expected value re-verified live on 2026-08-10. The fork-PR approval endpoint now exists on Free (the issue's row 2 is a normal assertion, seeded at the current `first_time_contributors`); repo-scoped rows cover `devkit` only.
- **`drift.yml`** — third leg wired into the scheduled run, output teed into the run summary. No token or permission changes: all reads are covered by the existing `DRIFT_REPOS_TOKEN` grants.
- **Docs** — README drift section + ADR-0002 correction (plan output is no longer the sole drift signal; issue-only semantics unchanged).
