## Summary

The one-time `all -> selected` visibility flip (#123) was executed in the UI on 2026-08-10; this PR re-aligns the declared `selected_repositories` lists with what was implemented, re-derived from a same-day sweep of every live default-branch `.github` workflow tree.

- **`COMMIT_APP_ID` narrows by three** (devkit, devkit-smoke-test, org-config): the devkit **1.7.0** adoptions re-scaffolded `sync-issues.yml` from `app-id` to `client-id`, so the 2026-08-07 sweep behind #126 went stale within 72 hours. Remaining consumers: commit-action + sync-issues-action (pre-1.7 `sync-issues.yml`) and the fully-legacy h5v + scitadel.
- **h5v and scitadel pre-seeded** into all three `*_CLIENT_ID` lists and the `DEVKIT_UPGRADE_APP_PRIVATE_KEY` union, so their eventual re-scaffold (#112) lands with working credentials on day one.
- **Comments refreshed** to the post-1.7.0 reality: `DEVKIT_UPGRADE_APP_CLIENT_ID` is consumed (devkit-smoke-test, org-config) since vig-os/devkit#1365 landed; maintenance-coupling note now points at whichever ID form a scaffold uses; canary note counts nine peers after #146.
- CHANGELOG `Unreleased -> Security` entry.

Config-only and inert for apply (dummy values are excluded from live-patch generation); the declaration is the documentation the future #116 assertion layer will check against.
