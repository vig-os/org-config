# [PR 289](https://github.com/vig-os/org-config/pull/289) docs(otterdog): refresh the App-installation evidence for the 1.6.1 pin

## Description

`README.md`'s App-installation-truncation bullet and `justfile.project`'s pin
comment both ask for two reads at **every** otterdog pin bump — re-read
`get_app_installations` in the new release, and re-measure each managed org's
installation count — because neither is a read the offline suite (ADR-0007) can
make. The pin then moved 1.5.0 → 1.6.1 in #283 as the mechanical five-literal
Renovate change #250 exists to raise, and neither read happened: nothing in the
diff the reviewer saw asked for them. The result was stale citation, not a
behavioural bug.

This PR re-makes both reads, writes the re-verified figures into the two places
that cite them, and moves the checklist to where the bump is actually adopted.
