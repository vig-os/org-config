# [PR 182](https://github.com/vig-os/org-config/pull/182) fix(hooks): allow `mis` so the devkit 1.10.0 upgrade can commit

Unblocks the scheduled `Devkit Upgrade` to 1.10.0, which has been failing at
"Commit the upgrade in the project shell" since the 1.10.0 release:

```
error: `mis` should be `miss`, `mist`
  .github/workflows/release-core.yml:641:54
```

Devkit renders `mis-parse` into the managed `release-core.yml` inside the
`DEVKIT_SYNC_TARGET` mirror-fold block. The word is spell-clean only under
devkit's own `.typos.toml` (which gained `mis = "mis"` in devkit#1488); the
consumer seed is never overwritten on upgrade, so this repo — the only one in
the org with a non-empty `DEVKIT_SYNC_TARGET`, hence the only one rendering the
block — never received the entry.

Adds the entry here with a comment pointing at the upstream fix. Drop it once
vig-os/devkit#1529 rewords the generated comment and nothing else needs it.

`prek run --all-files` green locally.

After merge: re-dispatch `Devkit Upgrade` with version `1.10.0`.

Upstream follow-ups filed: vig-os/devkit#1529 (generated content must lint under
the stock seed), #1530 (a failed upgrade leaves no branch/PR/issue), #1531 (the
mirror-fold render path is untested).

Refs: #181
