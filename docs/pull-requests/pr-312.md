# [PR 312](https://github.com/vig-os/org-config/pull/312) chore(config): declare revkit as a tier-A repository

Declares the new public `vig-os/revkit` with the same ADR-0008 tier-A shapes as `scitadel` (devkit 1.17.0 gitflow scaffold, will release through the devkit train):

- `Dev protection` / `Release protection`: `CI Summary` required, `commit-action-bot` bypass
- `Main protection`: house standard, `CI Summary`, `#OrganizationAdmin:pull_request`
- `Signed commits`, and `Tag protection` bypassed by `vig-os-release-app`
- House merge policy via `newRepo`; this also clears revkit from the drift sweep's undeclared inventory
- Ground-truth tests updated: +1 declared repo, +3 App bypass sites (20 → 23). `pytest`: 224 passed; `jsonnet` eval of the revkit block checked locally

- **Org secrets:** revkit joins the `selected_repositories` of the 8 App secrets `scitadel` has (`COMMIT_APP_CLIENT_ID/_ID/_PRIVATE_KEY`, `RELEASE_APP_CLIENT_ID/_ID/_PRIVATE_KEY`, `DEVKIT_UPGRADE_APP_CLIENT_ID/_PRIVATE_KEY`); `DECLARED_ORG_SECRETS` ground truth updated.

~~Merge blocker~~ **Resolved:** revkit's PR CI now triggers and passes (Actions reset + dependency graph enabled, see #311).

Apps: commit-action-bot, vig-os-release-app and vigos-devkit-upgrade are installed org-wide (`all`), so there's nothing to do by hand.
