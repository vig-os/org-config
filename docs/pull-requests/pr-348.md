#### Declared App slugs

Neither is exercised by the plan above, so config that fails either is green on review ([#259](https://github.com/vig-os/org-config/issues/259)). Both checks read the **declared** config only — an actor that exists live but is not declared needs a live ruleset read and is not covered.
