# [PR 335](https://github.com/vig-os/org-config/pull/335) chore(config): drop stepv's required Main approval

## Description

Removes the required approval from stepv's Main protection. stepv has one maintainer, who authors every PR, and GitHub refuses an author's own approval (`422: Can not approve your own pull request`). With the house count of 1, every green stepv PR sits at `REVIEW_REQUIRED`, and the only way in is the admin `pull_request` bypass. vig-os/stepv#50 is waiting there now: all 13 checks pass, CI Summary included.

**Decision for the reviewer:** ADR-0008 already accepts the admin bypass as the cost of 1 approval on a solo repo (Consequences). This PR swaps that routine bypass for a declared exception, the same count-0-with-required-checks shape as `devkit-smoke-test`. If you'd rather keep the ADR's position, close this, and stepv merges through the bypass, or through a second maintainer's approval.
